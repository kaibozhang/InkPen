# InkPen · 视觉契约 v3

> 方向：**INSTRUMENT（精密仪器）** — 以阳极氧化铝设备面板为母题。
> 由 A/B/C 三案交叉评审后合成，见 `review.html`。终稿 `final.html`。
> 改色只改本文件的 token 表，不在页面里散落硬编码。

---

## 1. 为什么是这个方向

三案同屏评审的结论：**高级感来自克制，不来自装饰**。

| 判据 | 结论 |
|---|---|
| 像不像一台贵设备 | 反白读数窗 + 丝印标签 + 1px 发丝线，最接近真机面板 |
| 会不会被记住 | 纸墨方向最强，但高级文具感会削弱「机床」属性 |
| 用三个月烦不烦 | 暗底 + 荧光长期看会累；亮灰面板最耐久 |
| 与产品契合 | 写字机不是代码编辑器，行号与控制台是噪音 |
| GDI+ 可做性 | 全 1px 线与实心块最稳；暗底细字抗锯齿会发糊 |

合成原则：`A 为骨 + C 的纸面朱砂线 + B 的明暗反差 − B 的荧光`。

## 2. 色板

四色家族，不许出现第五种颜色。

| 角色 | Token | 值 | 用在哪 |
|---|---|---|---|
| 板面 | `--plate` | `#E8E9E3` | 全局底色，模拟阳极氧化铝 |
| 凹槽 | `--bed` | `#DCDDD4` | 中栏画布底，比板面深一档，纸才会浮起 |
| 凹槽面 | `--well` | `#F5F5F2` | 输入框、次按钮的铣削面 |
| 纸 | `--paper` | `#FFFFFF` | 全屏唯一最亮面，只给纸 |
| 墨 | `--ink` | `#14161A` | 主文字、主按钮底 |
| 次级 | `--ink-2` | `#5A5F66` | 说明文字、标签 |
| 三级 | `--ink-3` | `#8C9298` | **仅丝印**（10px 以下、非必要信息），不承载正文 |
| 发丝线 | `--rule` | `#D6D8D2` | 所有分隔，代替阴影 |
| 发丝线强 | `--rule-2` | `#C2C5BE` | 边框、强调分隔 |
| 信号 | `--sig` | `#9A5716` | 状态点、轴号、当前值、选中步长（对板面 4.6:1） |
| 危险 | `--danger` | `#9B2C2C` | 只给急停 |
| 朱砂 | `--seal` | `#A63A2A` | **只允许出现在纸面上**（稿纸边线） |

**对比度**：墨/板面 15.8:1；`--ink-2`/板面 6.6:1；`--sig`/板面 4.6:1（AA）；`--ink-3` 不用于正文。

> `--ink-3` 是丝印专用色，只能画 9–10px 的大写拉丁编号（`MODEL A`、`WORK DRO`）。任何中文正文都不许用它——它达不到 AA。

## 3. 字阶

三档字号、三档字重，不多不少。

| 角色 | 字体 | 字号 / 字重 | 用途 |
|---|---|---|---|
| 读数 | Cascadia Mono → Consolas | 22 / 500，`tabular-nums` | DRO 坐标，全屏最大字 |
| 正文 | 系统中文栈 | 12.5 / 400 | 文稿、说明 |
| 标签 | 系统中文栈 | 11.5 / 400–500 | 参数名、按钮字 |
| 丝印 | Cascadia Mono | 9 / 400，字距 `.12em`，大写 | 面板编号与英文分区名 |
| 纸面 | KaiTi / 楷体 | 17 / 400，行高 29 | 纸上的手写字 |

**中文一律不做负字距**。数值可以 `-0.01em`，中文字符必须 0。

---

## 4. 形状与间距

- 圆角：`--r: 2px`，全系统唯一值。按钮、卡片、输入框统一 2px，不允许出现第二档。
- 描边：1px。GDI+ 下用 `SmoothingMode.None` 画 1px 线，或 `AntiAlias` + 半像素偏移，**绝不让它糊成 2px 灰线**。
- 间距基数 4px；常用 6 / 8 / 11 / 14。
- 分区靠 1px 发丝线 + 8–14px 留白，**不用卡片包裹、不用投影**。
- 唯一的投影给了纸：`0 1px 0 rgba(20,22,26,.07)`，一行都不多。

## 5. 组件规格

**主按钮**（`开始书写` / `生成 GCode`）
高 38，墨底 `--ink`，字 12/500 字距 `.04em`，右侧可挂一个 9px 等宽副标（`F 1200`）。悬停 `#24282D`，按下 `#0B0D10`。

**次按钮**
高 30，`--well` 底 + 1px `--rule-2` 边，悬停边线转 `--ink-2`。

**急停**
高 34，`--danger` 实心，白字，右端 `E-STOP` 丝印。全屏唯一红块，紧贴右栏底部。

**读数窗（DRO）**
反白块：`--ink` 底、`#EEEFEA` 字、22px 等宽右对齐，行高 44，行间 1px 深色分隔。左端 10px 轴号（`--sig-l`），右端 9px 单位丝印。三行等高，小数点必须垂直对齐。

**方向键**
40×40 直角方块，`--well` 底 + 1px 线，悬停转墨底白箭头。中间格放当前步长读数（9px 等宽），不放在角落。

**步长**
五个等宽方块，选中项墨底白字，未选中透明底。不用药丸、不用滑块。

**参数行**
左标签 + 点状引导线 + 右值（等宽，右对齐）。**不要每行再加一条整行虚线**，否则出现双横线。

**状态**
左上角一个 6px 方块（不是圆点，直角更硬）+ 中文状态 + 大写英文丝印（`待机 / IDLE`）。颜色只有三种：`--sig`（待机/运行）、`--danger`（报警）、`--ink-3`（离线）。

---

## 6. 状态语义（GRBL）

| 固件状态 | 显示 | 方块色 | 允许操作 |
|---|---|---|---|
| Idle | 待机 IDLE | `--sig` | 全部 |
| Run | 书写 RUN | `--sig` | 暂停 / 停止 |
| Jog | 移动 JOG | `--sig` | 停止 |
| Hold | 暂停 HOLD | `--sig` 闪烁 | 继续 / 停止 |
| Alarm | 报警 ALARM | `--danger` | 解锁 `$X` / 软复位 |
| Door | 门开 DOOR | `--danger` | 解锁 |
| — | 离线 OFFLINE | `--ink-3` | 连接 |

报警时 Jog 整块降透明度至 40% 并禁用点击，不许只把颜色变浅——颜色变浅在灰面板上看不出来。

## 7. 禁止清单

- ✗ 圆角 > 2px、药丸按钮、胶囊
- ✗ 投影（纸除外）、内发光、彩色阴影
- ✗ 渐变按钮、渐变分隔条
- ✗ 第五种颜色；朱砂出现在纸面以外的任何地方
- ✗ 两个红按钮同时存在
- ✗ 中文负字距
- ✗ 用 `--ink-3` 写正文
- ✗ 卡片套卡片（v2 的病根）

## 8. GDI+ 落地要点

| 规格 | 实现 | 风险 |
|---|---|---|
| 1px 发丝线 | `Pen(1f)` + `PixelOffsetMode.Half`，或 `SmoothingMode.None` | 高：默认会糊成 2px 灰线 |
| 2px 圆角 | `GraphicsPath` 四角 `AddArc(2,2)` | 低 |
| 纸的投影 | 手动画一条 1px 深线，不做模糊 | 低 |
| 悬停态 | `MouseEnter/Leave` + `Invalidate(rect)` | 低 |

**文字渲染分场景选，不许一刀切。** 这一条是编码阶段最容易吵起来的地方，先定死：

| 场景 | 用什么 | 原因 |
|---|---|---|
| 小字、浅底深字（12px 及以下正文、标签） | `TextRenderer.DrawText` | 走 ClearType，锐度是 GDI+ 的两倍，字不会灰 |
| 大字、纸面手写（17px 以上） | `Graphics.DrawString` | 能上灰度抗锯齿，曲线笔画边缘更干净 |
| 反白块上的小字（亮字坐深底） | 只许 `TextRenderer` | ClearType 在深底上会出彩色边纹 |
| 竖排 / 旋转文字 | 只许 `Graphics.DrawString` | `TextRenderer` 不支持变换矩阵 |

**由此推出一条硬规则：11px 以下的小字不许坐在深色填充上。** 这类组合只能二选一——要么把字提到 12px 以上，要么把它的容器从实心改成描边。反白读数窗里的 `MM` 单位就是这么处理的：不让它和数字一起坐深底，而是放到下方的浅色标注行。

> 如果哪天要做暗色版：GDI+ 在暗底上渲染细字会发糊，必须关掉 ClearType（`TextRenderingHint.AntiAlias`），并且把字重提高一档。这是暗色方向被判「实现成本高」的原因。

## 9. 与 v2 的差别

| | v2 | v3 |
|---|---|---|
| 母题 | 友好 SaaS | 精密仪器面板 |
