> 对比基准：GRBL-Plotter 1.8.1.0（2026-08-15）官方 Feature list
> 对比对象：InkPen 0.1.1-M1
> 用途：供你判断哪些值得加。**每项都标了对「写字机」这个定位的实际价值，不是越多越好。**

## 0. 先说清楚「简陋」这件事的性质

两者不是同一类软件，直接比功能条数会失真：

| | GRBL-Plotter | InkPen |
|---|---|---|
| 定位 | 通用 GCode 发送器 + 多格式绘图/雕刻前端 | 专用写字机上位机 |
| 输入 | SVG / DXF / HPGL / Gerber / Drill / CSV / 图片 / GCode / 文字 | **只有文字** |
| 输出目标 | 绘图笔、激光、拖刀、雕刻、钻孔 | 只写字 |
| 代码量 | 十万行级，十年积累 | 约 1.4 万行，M1 |
| 语言 | 英/德/中多语言 | 全中文 |

**所以差异分三类，处理方式完全不同：**

1. **真缺失**（InkPen 该有但没有）→ 建议补
2. **定位差异**（GRBL-Plotter 做的是绘图，InkPen 只写字）→ 不建议补，补了是负担
3. **本就更强**（InkPen 在中文书写上超出）→ 保持

下面按这三类列。

---

## 1. InkPen 反而更强的部分（先摆出来，避免只看到劣势）

| 能力 | InkPen | GRBL-Plotter |
|---|---|---|
| 中文单线字库 | **21666 码点**，主库带笔顺，含拼音带调、标点 | 仅 Hershey 西文 + 用户自备 |
| 中文排版 | 横排/竖排、首行缩进、居中、分页 | 无（文字只能转成西文路径） |
| 稿纸模板 | **横线 / 方格 / 田字格 / 拼音四线三格 / 自由**，可写入 GCode | 无 |
| 断点续写 | **按「第 N 个字」续写**，带 `(CH:…;PG:…;LN:…)` 元数据 | 按行号恢复，无字级语义 |
| 手写感 | 笔画扰动、收笔增强、种子可复现 | 无 |
| 部署 | 单 exe 绿色版，零外部 DLL，不写注册表 | 需 .NET + 多文件目录 |
| 缺字处理 | 多级回退链 + 缺字上报 | 无 |

这块是 InkPen 存在的理由，不建议为了「对齐 GRBL-Plotter」而稀释。

## 2. A 档：真缺失，建议补

### A1. 高度图 / 自动调平（Height map auto leveling）

| 项 | 内容 |
|---|---|
| GRBL-Plotter | 有，网格探测 + Z 补偿 |
| InkPen | 无，全网面一个固定书写 Z |
| 对写字机的价值 | **高**——写字是接触式作业，Z 深 0.05 mm 就可能拖墨，浅 0.05 mm 就断墨 |
| 工作量 | 3–5 人日（探测对话框 + 网格插值 + GCode 逐段 Z 补偿） |

**已实现**：网格 3×3（可调）自动探测 → 失败点用 4 邻域均值补 → 3×3 均值平滑去毛刺 → 双线性插值 → GCode 逐点 Z 补偿（仅当变化 ≥ 0.005 mm 才输出，未启用时 GCode 一字不变）→ 热力图可视化 → 存 `config/heightmap.json`。

**但先确认一件事再决定要不要做**：你的笔架是**刚性**还是**弹簧浮动**？

- **弹簧浮动笔架**：笔尖靠弹力压纸，本身就能吸收 ±0.5 mm 的平台误差。此时高度图收益有限，**优先级降到 C 档**。
- **刚性笔架**：Z 误差直接变成笔画误差。高度图基本是必需项。

很多成品写字机用弹簧笔架，这也是 GRBL-Plotter 的高度图主要服务于雕刻/激光（对刀深敏感）而非写字的原因。**不要因为「开源项目有」就默认自己需要。**

> 本机为**弹簧浮动笔架**，用户明确要求覆盖上述判断、A 档全做。修正后的理由见文首「实施状态」。

### A2. 进给倍率控制（Feed override）

| 项 | 内容 |
|---|---|
| GRBL-Plotter | 有，实时 +/- 按钮 |
| InkPen | **只显示不控制**（状态栏读 `Ov:` 显示百分比） |
| 价值 | 中高——书写中发现太快/太慢，现在只能停下重新生成整份 GCode |
| 工作量 | **0.5 人日**（实时指令 `0x90/0x91/0x92/0x93/0x94` 已有通道，加 6 个按钮即可） |

这是**性价比最高的一项**：改动极小，直接解决「写坏了只能整篇重来」。

**已实现**：−50 / −10 / +10 / +50 四个按钮，内部换算成 `0x92`/`0x91` 连发若干次（每档 10%）。注意 GRBL 没有「设为任意百分比」的实时指令，只有 100% / +10% / −10% 三种，所以按钮只能做步进。当前倍率仍从 `Ov:` 回报读。

### A3. 自动重连

| 项 | 内容 |
|---|---|
| GRBL-Plotter | 有，程序启动自动连上次端口 |
| InkPen | 无，每次手动选端口再连 |
| 价值 | 中——长时间书写、USB 抖动、机器休眠后掉线 |
| 工作量 | 0.5 人日 |

**已实现**：`ReconnectPolicy` 指数退避（1→2→4→8→16→30 秒封顶，默认最多 8 次），勾选框在「机器」页。用户**主动点断开**不触发重连；重连成功后状态栏提示「需重新设原点」——GRBL 掉电后位置不可信，这一步不能省。

### A4. 用户自定义指令按钮（宏）

| 项 | 内容 |
|---|---|
| GRBL-Plotter | 有，可配置按钮与快捷键 |
| InkPen | 只有一个自定义指令输入框，每次手打 |
| 价值 | 中——常用如「抬笔到安全高度」「移到换纸位」「清报警」 |
| 工作量 | 1 人日（按钮表存进现有配置文件即可） |

**已实现**：4 个按钮，双击/右键编辑，占位符 `{safez} {writez} {xyfeed} {zfeed}` 运行时展开；默认给「抬笔 / 试笔 / 回纸角 / 清报警」。独立存 `config/macros.json`（与原配置文件解耦，方便手动编辑/备份）。

### A5. 探测对话框（接触式测纸厚）

| 项 | 内容 |
|---|---|
| GRBL-Plotter | 有 |
| InkPen | 无，纸张厚度靠手填 |
| 价值 | 中——换纸后重设书写 Z 全靠试笔，容易出错 |
| 工作量 | 1–2 人日（`G38.2` 探测 + 回读 `PRBZ`） |

A1 与 A5 是配套的：不做 A1 也可以只做 A5（单点对刀），收益已有一半。

**已实现**：探测进度对话框实时显示「第 n/N 点」+ 逐点日志，可取消；单点模式探测完成后把 `接触Z + PressDepthMm` 直接写回书写 Z 并回填界面。`[PRB:x,y,z:1]` 中标志位 0 表示未接触，该点坐标不可用，做失败点处理。

## 3. B 档：可选，看你的实际用法

| # | 功能 | GRBL-Plotter | InkPen | 价值判断 | 工作量 |
|---|---|---|---|---|---|
| B1 | GCode 文件导入 + 2D 预览 | 有 | 无 | 想写「之前导出过的」「别人给的」GCode 才需要 | 1–2 人日 |
| B2 | 笔画级断点续写 | 按行 | 按字 | 长笔画多的字，断了要整字重写 | 1 人日 |
| B3 | GCode 变换（缩放/旋转/镜像/偏移） | 有 | 无 | 想小幅调整已生成文件时有用；重新排版更简单 | 1–2 人日 |
| B4 | 摄像头辅助对位 | 有 | 无 | 续写时对准已有笔迹、或在已印好的表格上填空 | **5–10 人日** |
| B5 | 日志导出为文件 | 有 | 只有屏内日志 | 出问题要我远程看日志时有用 | 0.5 人日 |
| B6 | 仿真变速/步进帧进 | 部分 | 有播放/暂时/单步 | 已够用 | — |

B4 单独说明：它是 GRBL-Plotter 最重的模块（摄像头坐标系、GCode 叠加、形状识别、示教）。对「在已印好的表格上填空」这类场景很香，但投入产出比取决于你是否真的要做套打。

## 4. C 档：不建议加（与定位不符）

| # | 功能 | 为什么不建议 |
|---|---|---|
| C1 | SVG 导入 | InkPen 的输出目标是「字」，不是「图形」。加了它就要处理路径、填充、图层、单位换算，等于换一个产品定位 |
| C2 | DXF / HPGL / Gerber / Drill 导入 | 同上，且面向 CAD/PCB，与写字无交集 |
| C3 | 图片导入（位图转路径） | 写字机画照片效果远不如绘图仪；且需描边算法 |
| C4 | CSV 导入 | 批量数据书写（如信封）可能有需求，但优先级远低于 A 档 |
| C5 | 激光支持（M3/M4、hatch fill、闭合路径重复） | 硬件形态不同，且激光有安全责任 |
| C6 | 拖刀补偿 / 极坐标 / 旋转轴 / 4·6 轴 / 第二台 GRBL | 硬件无关 |
| C7 | 条形码 / 二维码生成 | 技术上能写，但写字机写码速度慢、精度差，不如打印 |
| C8 | M98/M99 子程序、邮件/pushbullet 进度通知 | 写字场景用不上 |
| C9 | 工具表 / 自动换刀 | 单笔机器无意义 |

**反面提醒**：如果哪天你想让 InkPen 兼做绘图仪（写艺术字、画简单矢量图），那 C1/C2 就从「不建议」变成「核心」。这是产品方向问题，不是技术问题。

## 5. 我的建议排序

如果只做三件事：

1. **A2 进给倍率**（0.5 天，立竿见影）
2. **A3 自动重连**（0.5 天，消除一类低级故障）
3. **A5 单点对刀**（1–2 天，替代「试笔 + 手调」的玄学流程）

合计约 **2–3 人日**，能把「M1 能用」推到「日常可靠」。

**A1 高度图**单独看：先确认笔架类型。刚性笔架才做（3–5 天）；弹簧笔架跳过。

**A4 自定义按钮**属顺手项，可与 A2 一起做。

其余按需。

## 6. 与真机标定的关系

A1/A5 都依赖真机能动，**必须等你上机**。当前唯一能先做的是 A2、A3、A4、B5——这四项不碰硬件协议，纯软件。

如果你希望我先做，告诉我做哪几项即可。

> 2026-11-12 补记：A1/A5 的**软件侧已全部完成**，指令生成、回报解析、状态机、补偿输出都有单元测试覆盖（含故意改坏实现的注入验证）。仍未验证的是**真机行为**：
> - Z 轴行程够不够（探测要往下走 8 mm，抬笔要往上 5 mm）
> - 轴方向与 `InvertX/InvertY` 实际是否一致
> - 探针接线方式（是否与笔共用 Z 信号、接触时 `[PRB:]` 标志位是否置 1）
> - `ProbeFeedMmPerMin=100` 对你这台机器的实际合适值
>
> 这四项只能上机试，我不做猜测性默认值以外的承诺。
